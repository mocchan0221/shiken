# デモ

ブラウザで開くだけで、2 択に答えて価値尺度が自分に合っていく様子を試せるページです。Python も GPU も要りません。回答はどこにも送られません。

試験公開中: https://shiken.mocchan.net/ （`https://shiken-demo.pages.dev/` でも開けます。検索には載せていません）

## 使っているデータ

画像と音楽はすべて生成したもの、文は架空のものです。実在の人物や作品は含みません。

| データ | 中身 | 質問 |
| :-- | :-- | :-- |
| 料理 | MOSS-Image で生成した料理の写真 179 枚 | 美味しそう・辛そう・ヘルシー・高そう |
| 部屋 | MOSS-Image で生成した部屋の写真 119 枚 | 住んでみたい・落ち着く・片付いている |
| 風景 | MOSS-Image で生成した旅先の風景 120 枚 | 行ってみたい・寒そう・にぎやか |
| 動物 | MOSS-Image で生成した動物の写真 100 枚 | かわいい・かっこいい・怖い・飼ってみたい |
| 絵 | MOSS-Image で生成したいろいろな画風の絵 120 枚 | 好きな絵・かわいい・不気味・写実的 |
| 服 | MOSS-Image で生成した服のコーディネート（平置き）100 枚 | 着てみたい・フォーマル・派手 |
| 世界の音楽 | ACE-Step 1.5 で生成した 55 ジャンルの曲 110 曲（30 秒） | 好きな曲・ノれる・落ち着く |
| 日本語の歌 | ACE-Step 1.5 で生成した日本語の歌 100 曲（30 秒） | 好きな曲・ノれる・懐かしい |
| 小説のあらすじ | Claude が書いた架空の小説のあらすじ 120 本（12 ジャンル） | 読んでみたい・怖そう・泣けそう・笑えそう・壮大 |

画像は MOSS-Image（Apache-2.0）、音楽は ACE-Step 1.5（MIT）で生成しました。

## できること

1. データ（画像や音の集まり）と質問を選ぶ（例: 生成した料理と「美味しそう」）。
2. 2 つずつ出てくる項目のうち、質問により当てはまる方を選ぶ（キーボードの ← → ↓ でも答えられる）。
3. 答えるたびに、全体の並びが入れ替わる。各項目に、回答 0 件の並びからどれだけ動いたかが出る。
4. 答える前の予想が当たったかと、直近 10 問の的中率が出る。
5. 「あなたの価値尺度を言葉にすると」に、高く見る語と低く見る語が出る。
6. 価値尺度ファイルを保存・読み込みできる。回答はブラウザの保存領域にも残るので、開き直しても続きから答えられる。

## 自分の画像で作る

1. 設定ファイルを書く。`sets.example.json` を写して `sets.json` にし、画像のフォルダと質問を書き換える。

   | 項目 | 意味 |
   | :-- | :-- |
   | `id`, `label`, `note` | データの名前と、画面に出す名前・説明 |
   | `folder` | 画像（または音）のフォルダ。設定ファイルからの相対パスか、絶対パス |
   | `kind` | `image`・`audio`・`text`（1 件 1 つの .txt。1 行目を見出しとして出す） |
   | `concepts` | 概念の語（`food` / `art` / `ui` / `photo` / `face` / `music` / `story`）。省くと補正の中身を出さない |
   | `questions` | 質問ごとの `id`、`label`（ボタンの名前）、`prompt`（2 択の問いかけ）、`question`（[価値尺度ファイルの形式](../docs/profile-format.md) の質問の定義と同じ） |

2. 書き出す（EmbeddingGemma 2 が要る。GPU が無ければ CPU で、画像 100 枚で 2 分ほど）。

   ```bash
   pip install -e ".[eg2]"
   python demo/build.py demo/sets.json
   ```

   `demo/data/`（パック）、`demo/thumbs/`（縮小画像）、`demo/shiken.js`（ブラウザ版の写し）ができます。項目の名前は「データの id / ファイル名」になり、元のフォルダのパスはページに出ません。

3. 開く。ES モジュールはファイルを直接開くと読み込めないので、手元でサーバーを立てます。

   ```bash
   python -m http.server -d demo 8000     # http://localhost:8000 を開く
   ```

## 公開のしかた

書き出したもの（`demo/data/` など。今のデモで約 130 MB）は git に入れず、手元から Cloudflare Pages に上げます。

```bash
npx wrangler@3 login                                   # 初回だけ。ブラウザで Cloudflare にログインする
python demo/deploy.py --deploy --project shiken-demo   # dist/ に集めて調べてから上げる
```

`deploy.py` は、許可した種類のファイル（`index.html`・`shiken.js`・`data/` の JSON・`thumbs/` の画像・`audio/` の音）だけを `dist/` に集めます。集めた文のファイルに、手元のパス（ドライブ名やユーザーのフォルダ）や価値尺度ファイルの名前が混ざっていないかを調べ、見つかれば上げるのをやめます。あわせて、読み込み先を自分のサイトと Google Fonts に限るなどのセキュリティ用のヘッダー（`_headers`）を付け、検索に載らないようにします。wrangler の最新版は Node.js 22 以上が要るので、Node.js 20 では `wrangler@3` を使います。
